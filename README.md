# Lawyer Email Search

A proposed tool for expert witnesses to search large Outlook email archives, follow conversations, and locate relevant source material by topic, correspondent, and case role.

AI may assist software development. The MVP itself will use non-AI processing and search; the expert witness will interpret the evidence and draw conclusions.

## Current Status

The project is in scope definition and market evaluation. The initial direction has been discussed, but the technical design, platform priority, and decision to build versus adopt an existing product remain open. There is no application code, dependency setup, or runnable test suite yet.

The MVP is intended to run locally on Mac or Windows. Cloud hosting and optional AI analysis are longer-term possibilities.
